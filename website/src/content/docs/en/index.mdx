<Feature title="Any model, the same tools" href="/mojocode/en/config/providers/" linkText="Models and providers">
  <div slot="text">
    <p>Presets for Kimi, DeepSeek and GLM; any OpenAI-compatible endpoint (vLLM, Ollama, a gateway) is one `providers` entry away. Model lists are fetched live, never hardcoded.</p>
    <p>Thinking levels follow what each model actually supports: `/think` lists only what the catalog says exists, and models the family table cannot describe take raw parameters per model.</p>
  </div>
  <Terminal title="mojocode" html={models.en} compact />
</Feature>

<Feature title="Breakage shows up immediately" href="/mojocode/en/config/lsp/" linkText="LSP diagnostics" flip>
  <div slot="text">
    <p>After every write / edit, the language server's errors and warnings ride back to the model with the tool result, including "editing A broke B". Installed servers are used; missing ones are skipped silently.</p>
    <p>Long investigations go to a subagent with its own context and step budget; only the conclusion returns. The explore kind gets read-only tools.</p>
  </div>
  <Terminal title="mojocode" html={feedback.en} compact />
</Feature>

<Feature title="Sessions you can go back to" href="/mojocode/en/guides/sessions/" linkText="Sessions">
  <div slot="text">
    <p>Every conversation is an append-only JSONL log that is always complete on disk. `-c` continues the latest, `-r` picks one, `--fork-session` branches off an old one; in the TUI, esc esc rewinds to any message.</p>
    <p>Past 80% of the context window the history is compacted into a summary and the session keeps going; replay still shows the original conversation.</p>
  </div>
  <Terminal title="zsh" html={sessions.en} compact />
</Feature>

<Feature title="No permission system. Extensions instead." href="/mojocode/en/extensions/overview/" linkText="Extensions" flip>
  <div slot="text">
    <p>Same stance as pi: no prompts, no sandbox levels, no plan mode. The boundary belongs to a container or a disposable working copy; that is the fence that actually holds.</p>
    <p>To intercept, drop a TypeScript file into `~/.mojocode/extensions/`: veto in `tool_call`, rewrite in `tool_result`, register commands and tools, show a status line. The built-in /goal, /review, todo, MCP and LSP use the very same API.</p>
  </div>
  <Terminal title="guard.ts" html={extension.en} compact />
</Feature>
