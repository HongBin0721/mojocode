TUI 运行在 alternate screen(全屏,类似 vim):滚轮、`PageUp`、`PageDown` 回看时间线,上滚自动暂停跟随,滚回底部恢复;退出时整场会话以纯文本写回终端,历史仍可翻可复制。

## 复制文本

直接拖选即可,松手自动写入系统剪贴板(tmux copy-on-select 风格,底栏回显「已复制 N 个字符」;SSH 场景经 OSC 52 送达本机,iTerm2 需在设置里允许「Applications may access clipboard」)。也可按住 `shift`(macOS 上 `option`)拖选走终端原生复制。

## 按键

| 操作 | 说明 |
|---|---|
| 直接打字回车 | 提需求 |
| `esc` | 中断正在执行的任务 |
| `esc` `esc`(空闲时) | 打开回退选择器,见下 |
| `ctrl+c` 两次 | 退出 |
| 滚轮 / `PageUp` / `PageDown` | 回看时间线。滚轮停在命令菜单、文件菜单或选择器上时滚的是那份列表,不会连带滚动时间线 |
| `ctrl+o` | 循环时间线密度:`full` → `compact` → `result`(`/focus` 可落盘) |
| `ctrl+r` | 展开 / 收起详情:思考正文与工具输出默认折叠成一行 `+ N 行输出`。diff、任务清单是结果,从不折叠 |
| `ctrl+t` | 折叠 / 展开工作中的实时任务面板(todo 清单) |
| 鼠标点击 | 回退选择器、`/setting` 面板的列表行点一下即选中。按下与抬起要落在同一格才算点击,拖选复制不会误触 |
| `shift+enter` | 输入框内换行(需终端支持 kitty 键盘协议:iTerm2 3.5+ / kitty / WezTerm / Ghostty) |
| `option+enter` / `ctrl+j` / 行尾 `\` 回车 | 换行的兜底按键,任何终端可用 |
| `↑` / `↓` | 翻历史输入;多行草稿内为上下移动光标 |
| 输入 `/` | 命令菜单,`↑`/`↓` 选择、回车执行、`tab` 补全 |
| 输入 `!<命令>` | 在工作区跑一条 shell 命令(Pi 同款),输出并入对话上下文但不开轮——下一次提问模型自然看到;扩展的 `user_bash` 钩子可以改写或接管它 |
| 输入 `@` | 文件模糊补全,回车或 `tab` 插入路径。提交时被引用的文件内容自动附给模型;`@截图.png` 等图片作为图片附给支持视觉的模型(png/jpg/gif/webp,单张 ≤ 5MB) |
| `ctrl+v` | 粘贴剪贴板里的图片:输入框出现 `[image #N]` 占位,提交时随消息发出(macOS 为主平台,Linux 需 `xclip` 或 `wl-paste`) |

图片长边超过 1568px 时自动等比降采样,格式不变;全部图片另受 5MB/张、10MB/条的上限约束。当前模型不能直接收图时,图片降级为文件引用,模型需要看图时调 `view_image` 工具换取文字描述,见[视觉模型](/config/providers/#视觉模型)。

## 斜杠命令

内置命令在前,扩展命令其次,技能最后;同名时内置优先。带枚举参数的命令(`/provider` `/think` `/focus` `/theme` `/review`)在菜单上回车会进入二级选择器;`/models` 不带参数回车打开按厂商分组的模型选择器。

| 命令 | 作用 |
|---|---|
| `/help` | 列出所有命令 |
| `/init` | 分析代码库并生成或改进项目根目录的 `AGENTS.md` |
| `/review [范围]` | 评审 git 改动,输出按严重度排序的发现清单,只读。见[评审与清理](/features/review/) |
| `/simplify [目标]` | 审查变更代码的清理机会并直接应用修复。见[评审与清理](/features/review/) |
| `/goal [条件\|clear]` | 目标模式:给一个完成条件,每轮结束自动检查、没达成就接着干。见[目标模式](/features/goal/) |
| `/models [id]` | 切换模型。不带参数打开分组选择器,输入即搜索,`←`/`→` 折叠展开分组;`/model` 是别名 |
| `/provider [id]` | 切换服务商。不带参数打开选择器,已配 key 的直接切,未配的就地输入验证 |
| `/think <档位>` | 思考强度。可选档位随当前模型而定,见[思考档位](/config/providers/#思考档位) |
| `/setting` | 设置面板:界面语言、状态栏显示项。`↑`/`↓` 选择、回车进入、`esc` 逐级返回;状态栏是多选,空格勾选、回车生效。改动即时生效并写入全局配置 |
| `/focus <full\|compact\|result>` | 时间线密度并落盘。`full` 全量,`compact` 把成段的工具调用折叠为「⋯ N 个工具调用已折叠」,`result` 只看问答。回答、报错与各类提示在任何档位都不隐藏 |
| `/theme <name>` | 运行期切换配色主题并落盘;选择器列出项目 / 全局 `themes/` 目录与包带的主题目录里的每个 `<name>.json`,光标到哪套预览哪套,`default` 回到内置配色;生效中的主题文件保存即重画(见[包管理](/extensions/packages/#主题)) |
| `/compact` | 手动压缩上下文 |
| `/new` | 开启新会话(保留屏幕内容) |
| `/clear` | 清屏并开启新会话 |
| `/resume` | 切换到本目录的另一个历史会话 |
| `/fork` | 把当前对话分叉进新会话继续,原会话停在分叉点不再变动 |
| `/skills` | 重扫并列出技能 |
| `/reload` | 重载磁盘上的扩展(内置扩展不动) |
| `/mcp` | 查看 MCP 服务器状态 |
| `/doctor [offline]` | 体检,读会话此刻的配置;`offline` 跳过联网检查 |
| `/cost` | 本次会话 token 用量 |
| `/exit` | 退出;`/quit` 是别名 |

## esc esc 回退

空闲时连按两次 `esc` 打开回退选择器,选中一条历史消息即把对话截断到它之前,原文回到输入框,编辑后重发,相当于从那一点分叉重来。回退是真实的删除,模型历史与展示历史一起裁掉。

## 状态栏与状态行

底栏两组:左边模型、工作目录、思考档位,右边上下文用量条与总 token。显示哪些段在 `/setting` 里勾选。

输入框的顶边就是工作状态行:工作中显示 `── ⠋ 思考中 · 12s · esc 中断 ──`,空闲时是一条普通的分隔线。扩展可以在输入框上方再挂一行自己的状态(比如 `/goal` 的「目标 3/10」),带计时的条目由客户端自己走秒。
